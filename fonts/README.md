# Fonts

Self-hosted [Syne](https://fonts.google.com/specimen/Syne) and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (SIL Open Font License 1.1).

Metric-matched fallback faces in `fonts.css` are generated with [fontpie](https://github.com/pixel-point/fontpie) to prevent layout shift during `font-display: swap`.
